# Pilot 首轮界面适配

2026-10-24。本轮从已验证的 nanoMuse 执行基线进入阶段 2，不再把原上游桌面作为 Pilot 的界面交付。

当前界面更新：按后续要求已移除“关于 Pilot”页面、网页及原生菜单入口，以及侧栏“基于 DeepSeek Harness”页脚。下文早期关于页的记录仅表示历史实现；源码许可证、NOTICE 和来源文件不删除。

## 已实现

- Pilot 独立图形标记、首页欢迎区、窗口标题和关于页；关于页保留 nanoMuse GPL、DeepSeek Harness MIT 来源说明。
- 双列侧栏：52px 图标栏，第二列显示 Pilot、搜索和 nexo／会话／项目三组；浅色中性背景、紧凑列表和圆角选中状态。
- 图标栏仅保留聊天、搜索和左下角菜单；移除动态形象以及 Feed、Ideas、Goals、Library、最近文档等首版外围入口，不删除其共享后台服务。
- 左下角菜单保留快捷键、报告问题、设置、关于、已有自动化任务和插件，以及聊天列表收起/展开；设置没有独立图标。支持外部点击、Esc、方向键与焦点恢复。
- 对话头部改为简洁 Pilot 状态栏，继续订阅原运行、审批、等待、完成状态；消息、输入框、工具卡片、审批与停止仍使用原链路。
- “稍后配置，先进入首页”仅保存本地引导展示偏好，不伪造模型就绪、账号或操作授权；帮助页主动重开引导仍可进入。
- 本地项目导航接入 DSH：系统目录选择 → `workspaces.create({path})`，已有 `WorkspaceView.sessionIds` 负责会话成员；项目的加号调用原 `sessions.create({workspaceId})`。没有新建历史格式或数据库。
- 普通会话显式使用 DSH 默认工作区，避免从项目界面创建时沿用当前项目；项目成员不加入本地 nexo/普通会话候选。项目组只额外保存工作区 ID 的本地导航偏好。

## 会话多标签

会话内容区新增标签栏：从左侧打开或新建会话时追加标签，已打开的会话只激活现有标签；支持横向滚动、拖拽前后插入排序、关闭按钮、中键关闭，以及右键关闭当前/其他/右侧/全部。标签上的运行/等待标记继续读取 DSH 状态。方向键与 Home/End 切换标签，Delete 关闭焦点标签；右键菜单支持方向键、Esc 与焦点返回。

标签列表、顺序和选中 ID 仅作为本地界面偏好保存于 `pilot.session-tabs.v1`。切换继续调用原 DSH `openSession`，不创建新数据库、消息历史或执行队列。关闭标签不归档、不删除会话，也不调用取消；最后一个标签关闭时显示空工作区，原会话及任务生命周期继续由 DSH 管理。可以从左侧重新打开；刷新可恢复标签顺序和选中项（Host 重启与跨设备恢复未在本轮验收）。全部关闭时 DSH 当前绑定保留，内容和输入框在空工作区下隐藏，避免借用非公开的清空导航接口或额外创建会话。

实测：真实 Chromium 鼠标拖拽换位；分别输入两份未发送草稿并切换，草稿独立保留后已清空；关闭非当前标签不改变当前会话；右键关闭右侧/其他/全部按预期生效；关闭全部后左侧记录仍在并可重新打开；刷新后的标签顺序/选中状态与空状态均检查通过；菜单方向键、Esc 和焦点返回通过。检查没有发送模型请求，运行中任务的实际持续/停止行为仍属于执行层验收。本轮修正了 DSH 列表同步滞后导致新建空白标签被过早移除的问题，不把缺少瞬时列表项当作会话已删除。
